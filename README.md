# سایت کارگروه کیفیت‌بخشی آموزش ابتدایی مبارکه — نسخه‌ی ری‌اکت

## اجرا روی رایانه‌ی خودتان

```bash
npm install      # نصب وابستگی‌ها (یک بار)
npm run dev      # اجرای حالت توسعه روی http://localhost:5173
npm run build    # ساخت نسخه‌ی نهایی در پوشه‌ی dist
npm run preview  # بررسی نسخه‌ی نهایی پیش از انتشار
```

## ساختار

```
src/
  main.jsx            نقطه‌ی شروع برنامه
  App.jsx             مسیرها (Routing)
  data/site.js        همه‌ی محتوا؛ برای تغییر متن‌ها فقط همین فایل را ویرایش کنید
  components/         اجزای قابل استفاده‌ی مجدد
  hooks/              منطق مشترک: تم، انیمیشن ظهور، مدیا کوئری
  pages/              صفحه‌ها
  styles/global.css   ظاهر سایت
public/docs/          فایل‌های PDF و HTML و اکسل برای دانلود
```

## افزودن یک صفحه‌ی تازه

۱. در `src/data/site.js` یک شیء تازه به آرایه‌ی `pages` اضافه کنید (slug، title، lead، sections).
۲. در همان فایل، آدرس صفحه را به آرایه‌ی `nav` اضافه کنید.
تمام؛ مسیر و فهرست و صفحه خودکار ساخته می‌شوند.
